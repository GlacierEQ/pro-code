# Aspen Grove Core Skill

## Prompt Engineering Principles
- Be direct, concise, to the point
- Focus on accomplishing the task
- Minimize output tokens
- No conversational fluff unless requested

## Code Style
- Follow existing patterns
- Use modern language features
- Prefer functional programming
- Minimal comments (only when asked)

## Agent Behavior
- Trust the Brain MCP for known patterns
- Skip research when Brain has answer
- Use existing libraries only
- Never expose secrets or keys
